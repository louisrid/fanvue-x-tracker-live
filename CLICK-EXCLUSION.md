# Excluding your own clicks
Open https://elegant-swan-98c20a.netlify.app/click-preferences.html in each browser and select “Exclude my clicks in this browser”.

The first-party Secure SameSite=Lax cookie applies across the site's tracking routes. Redirects retain their destinations and permanent tracking IDs, while the handler skips the event write. No IP addresses are stored or blocked. Shared iCloud Private Relay addresses are unsuitable for identifying one person.

The preference lasts up to one year, subject to browser cookie retention. Clearing cookies, using a private window, another browser/profile or an in-app browser requires opting out again. The preference only excludes this tracker’s click records; it does not suppress destination analytics or X metrics, and does not alter historical events.

Use “Count my clicks again” to reverse the setting. Local redirect tests cover exclusion and exact cookie matching. Live verification must use the excluded cookie or authenticated isolated test mode; normal production test clicks would affect real totals.
