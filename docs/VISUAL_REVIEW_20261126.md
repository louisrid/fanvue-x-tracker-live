## History rules

Every visible time-series graph uses chunky rounded pink bars for individual days. Hover, focus or tap highlights the bar and opens a dark card with its full date and exact value. Values are never accumulated across periods. Daily plots retain any verified dated observations, including new campaigns with one or two days; there are no weekly or cumulative graph options. Desktop shows up to 14 daily bars in a full-width feature; mobile shows the latest seven in a short single-row strip. Weekly aggregation remains in the weekly results table. Empty histories remain omitted. Source gaps remain gaps; incomplete current periods retain their definition on hover. Click history takes priority over views when available.

## Traffic definition

The single Dashboard Clicks figure sums available recorded clicks from disjoint GTA, article and OF campaign URL sets. Provider filtering differs, so this is recorded link activity, not unique people or an exclusively human-filtered count. The source readings and limitations are preserved on hover. A weekly count excludes unavailable undated sources and is marked internally as a subtotal. Discord clicks and the duplicate Viral view never enter this promotion total.

## Article titles

Eleven published article headlines were verified through the existing X metrics provider, matching each response to the source post ID. The verified title snapshot makes existing articles readable immediately; future source refreshes retain the title field alongside the same post identity. Internal article references remain in the source and details. Unavailable titles are not invented.

Dashboard Views now includes distinct Guru promoted originals, using the same X status-ID deduplication as other campaigns. This measures overall promoted-post exposure including organic views; external viral originals remain excluded.

## Stronger visual contrast

Headline figures are 46px/900 weight on desktop and 36px on phones, with automatic fitting for long amounts. Campaign-tinted KPI fills, filled active tabs, brighter table headers and visibly raised grey controls distinguish the page layers. Primary refresh actions are pink with white text. Links never use underlines, including hover/focus states; colour and focus rings retain affordance. The rectangular Back control is larger, with 48px desktop/32px mobile space above it. The sidebar layout is retained.

Viral QRT daily clicks use verified Short.io human-click custom intervals starting at each post’s publication time. The existing server-side refresh caches these readings; failures retain previous verified values and missing days do not become zero. The same readings power the Mandy view. The Dashboard graph sums disjoint dated recorded link readings and explains the available sources on each day’s hover card. Accounts remains a publisher database without a graph.
